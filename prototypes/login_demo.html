نموذج تجريبي لتسجيل الدخول (Phase 1) — يستدعي POST /auth/login فعليًا على الـ API. لازم الـ API يكون شغّال ومتاح من نفس الجهاز اللي بتفتح الصفحة دي عليه.

غيّره لو الـ API شغّال على عنوان تاني (سيرفر تطوير، أو بيئة منشورة لاحقًا).
القيم الافتراضية هي حساب المدير اللي بيزرعه prisma/seed.ts — غيّرها فورًا في أي بيئة حقيقية.
